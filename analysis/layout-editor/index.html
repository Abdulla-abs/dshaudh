怎样编写布局

  1. 放建筑。点击左侧建筑后，在格子上放置；或直接拖入画布。
  2. 调位置。用“选择”工具拖动建筑，右侧可精确填写坐标和等级。方向键移动一格。
  3. 画围墙。切到“画墙”，按住鼠标拖动。格子被占用时会跳过，不覆盖建筑。
  4. 设守军。选中旗子或龙弹堡，在属性中添加英雄并设置等级。
  5. 导出文件。点击“导出布局”，把下载的 JSON 文件交给我接入游戏。

浏览器会自动保存当前布局。重要版本请导出文件备份。导入或新建也可以撤销。
