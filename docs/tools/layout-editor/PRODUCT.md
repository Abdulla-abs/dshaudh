# 关卡布局编辑器

## Register

product。本地单人工具，服务于关卡编辑。

## 用户与目的

用户在 Windows 电脑上对照游戏截图，亲自摆放敌方建筑、围墙和守军。导出文件后交给代码维护者接入原游戏。用户已确认拖放、等级、连续画墙、守军绑定和文件导出的工作方式。

## 设计原则

以准确的原版占地和格子坐标为准，避免继续猜截图坐标。保存操作可撤销，旧布局可导入。工具不连接账号、不修改存档、不自动安装游戏。建筑显示为带名称的占地示意，不冒充原版画面。

## 使用环境

白天在电脑屏幕前，一边查看游戏参考图，一边逐格调整。控制区采用明亮中性底色，地图使用低饱和草地底色。文字保持清晰，图形颜色同时配合名称识别。
