# 本地满级升级测试版

双击 `启动本地满级升级测试.cmd`，再点击原版入口的“进入游戏”。本版在五级包之上，按原表 `data.unit_main` 接满全部可升级等级。

| 建筑 | 最高等级 | 满级主要效果 |
| --- | --- | --- |
| 龙首之城 | 10 | 模型到十级；仓库贡献仍各 20000 |
| 日光井 | 10 | 产量 2500/小时，暂存 100000 |
| 龙银矿 | 10 | 产量 2500/小时，暂存 100000 |
| 日光皿 | 10 | 日光仓库 2500000 |
| 龙币库 | 10 | 龙币仓库 2500000 |
| 龙英巢 | 10 | 模型到十级 |
| 驯龙场 | 8 | 模型到八级（原表止于此） |
| 建筑师小屋 | 1 | 仍不可升级 |

两座仓库都到十级后，总容量各约 2520000（主城各 20000 + 仓库各 2500000）。费用、耗时与主城依赖等级全部读取原表当前等级配置。

实现为运行时生成 `upgradeTypes`（建筑族 201–207），不再按级硬编码。新存档键为 `dino.local.city.v8`，会从 v7 及更早键复制。包为 `dino-local-max.apk`。

本版未改升级状态机，只扩展映射范围；未再跑完整升级夹具验证。原表扫描见 `analysis/max-native-configs.json`。完整主城、新建建筑、养成和战斗仍未恢复。

## 开发入口

```powershell
python analysis/make_max.py
python analysis/build_max.py
```

交付脚本为 `analysis/max_boot.js`。`Launch-Max.ps1` 设置 DirectX、重启专用实例、安装并启动。
